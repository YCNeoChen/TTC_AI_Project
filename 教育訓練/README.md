# 教育訓練

## 緣起

執行長與江副對研企組應用 AI 的方向與策略有所期待，因此成立組內 AI 工作小組（2026/11/24 來信）。

- **成員（暫定）**：大溶、予勁、柏康
- **首要目標**：提升組內同仁（含外部幫手）的 AI 運用能力
- **時程壓力**：明年度各計畫的投標作業即將開始
- **推動方式**：以工作坊的方式規劃與執行
